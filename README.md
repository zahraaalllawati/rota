# PICU on duty

The page behind zahraaalllawati.github.io/rota: who is on in PICU, HDU and the RRT, day and night.

This repository holds only the page, its icon and its typeface. It keeps no names. Each time the
page is opened it reads the current rota through a Google Apps Script link, and that script reads
the rota sheets with view-only permission.

- To change who is shown, change the rota. Nothing here needs touching.
- To change the page itself, replace `index.html`.
- On a phone: open the address, then Share > Add to Home Screen (iPhone, in Safari) or the menu >
  Add to Home screen (Android, in Chrome).

The typeface is Barlow Semi Condensed, used under the SIL Open Font Licence (see
`barlow-font-licence.txt`).
